# Halaman About

## Tujuan

Memberikan informasi tentang marketplace bonsai, latar belakang, dan tujuan platform.

## Status Implementasi

Sudah diimplementasikan sebagai halaman statis.

## Fitur yang Tersedia

- Menjelaskan latar belakang platform bonsaiku.
- Menyampaikan nilai jual dari komunitas bonsai (menyediakan ruang jual-beli agar tidak spam grup WhatsApp).
- Halaman statis yang mudah diakses dari navigasi utama.

## Catatan Implementasi

- Komponen Livewire: `App\Livewire\About`.
- Route: `GET /about` dengan nama `about`.
- Halaman ini dapat diakses tanpa login (publik).
- Konten bersifat statis dan dapat diubah langsung di view Blade terkait.
